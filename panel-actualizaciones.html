Opción manual vía Base de Datos (SQL)

Si prefieres actualizar directamente desde PostgreSQL (DBeaver, psql, Render DB), puedes copiar esta consulta:

-- Ejecutar en PostgreSQL INSERT INTO configuraciones (clave, valor) VALUES ('version_app_representante', '1.0.1'), ('apk_url_representante', 'https://expo.dev/artifacts/eas/...apk'), ('novedades_representante', 'Soporte para comprobantes en PDF'), ('obligatoria_representante', 'false') ON CONFLICT (clave) DO UPDATE SET valor = EXCLUDED.valor;
